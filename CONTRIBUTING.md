# Contributing

Contributions are welcome for noncommercial research and interoperability work.

Before opening a pull request:

- read `AGENTS.md`, `SECURITY.md`, and `IP_PROVENANCE.md`;
- keep the native host lightweight and the heavy work out of the shell-facing process;
- preserve x64 and ARM64 build paths;
- run the targeted build and smoke test;
- run a secret/provenance review;
- describe AI assistance and human review when applicable.

By submitting a contribution, you confirm that you have the right to submit it under the repository license and that no confidential or secret material is included.
